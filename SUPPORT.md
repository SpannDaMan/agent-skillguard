# Support

For non-sensitive defects and questions, open a GitHub Issue at `https://github.com/SpannDaMan/agent-skillguard/issues`. Include the command, exit code, Python version, rule-pack version, a bounded redacted report, and a minimal safe fixture.

Do not send real credentials, proprietary skill contents, or harmful payloads. This project provides no public SLA, hosted service, or account support. Use the private security-reporting path in [SECURITY.md](SECURITY.md) for vulnerabilities.
